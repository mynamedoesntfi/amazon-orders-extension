┌─────────────────────────────────────────────────────────────────────────┐
│                         MESSAGE FLOW                                    │
└─────────────────────────────────────────────────────────────────────────┘

    User clicks extension icon
            │
            ▼
    Popup opens (App.tsx)
            │
            ▼
    useOrders() hook initializes
            │
            ▼
    chrome.tabs.sendMessage({ type: "SCRAPE_ORDERS" })
            │
            ▼
    Content Script receives message
            │
            ▼
    scrapeOrders() executes:
      ├─ Process page 1
      ├─ Discover page URLs
      ├─ Prefetch pages (parallel)
      ├─ Execute in iframes (concurrent batches)
      └─ Extract order data
            │
            ▼
    Response: { orders: Order[] }
            │
            ▼
    Popup displays orders
            │
            ▼
    User clicks "Export"
            │
            ├─→ CSV: Downloads to local folder
            └─→ Google Drive: OAuth → Upload

┌─────────────────────────────────────────────────────────────────────────┐
│                      KEY TECHNICAL FEATURES                             │
└─────────────────────────────────────────────────────────────────────────┘

  • Concurrent Page Processing
    └─ Prefetches multiple pages in parallel
    └─ Executes iframes in batches (2 concurrent)
    └─ Processes results in order

  • Client-Side Decryption Handling
    └─ Amazon uses encrypted order data
    └─ Executes pages in sandboxed iframes
    └─ Waits for SiegeClientSideDecryption scripts

  • Error Handling
    └─ Fallback to DOMParser if iframe fails
    └─ Graceful degradation for failed pages
    └─ User-friendly error messages

  • Type Safety
    └─ Full TypeScript implementation
    └─ Type definitions for Order, OrderItem
    └─ Type-safe message passing
